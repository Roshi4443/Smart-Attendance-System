# Smart Attendance System (Interview Version)

A simple academic demo using Python, OpenCV and SQLite.

## Features
- Register a student with a captured face image
- Detect faces from webcam using OpenCV Haar Cascade
- Store student details and face image path in SQLite
- Mark attendance manually after face detection

## Run
pip install -r requirements.txt
python app.py

Note: This interview version intentionally keeps recognition simple and transparent.
For true face recognition, a face-embedding library can be added later.
